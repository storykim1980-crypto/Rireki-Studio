印刷

履歴書の印刷方法まとめ
コンビニ・自宅プリンターの手順と用紙選び

Webで作った履歴書も、最後の「印刷」で印象が決まります。かすれた文字・ずれた余白・安っぽい用紙は避けたいところ。この記事では、今日使える3つの印刷方法と、失敗しない用紙選びをまとめます。

この記事の目次

  1. まずはPDFで保存するのが安全
  2. コンビニプリントの手順
  3. 自宅プリンターの設定
  4. 用紙の選び方

まずはPDFで保存するのが安全

ブラウザの「印刷」から宛先を「PDFに保存」に変更するだけで、文字が埋め込まれた綺麗なPDFが作れます。

  • 用紙サイズ：A4・余白：なし・倍率：100%（既定値）
  • カラー印刷（写真入りの場合）/ モノクロでも写真は選べるものを
  • 保存したPDFはスマホに入れておけば、いつでもコンビニで再印刷できます
当サイトの履歴書作成画面の「印刷 / PDF保存」ボタンは、A4ぴったりのレイアウトで出力されます。プレビューをそのままPDF化できるので設定迷いなし。

コンビニプリントの手順

大手コンビニのマルチコピー機なら、USBメモリや専用アプリでPDFを印刷できます（詳細な手順は各社の公式案内をご確認ください）。

  1. 保存したPDFをUSBメモリまたはスマホアプリに入れる
  2. コピー機で「文書プリント（普通紙）」を選択
  3. A4・カラー・100%を指定（写真が小さくならないよう）
  4. 試し刷り1枚→確認してから必要枚数を印刷
同じPDFでも「原寸大（など）」以外の設定（「用紙に合わせて印刷」）では縮小されて写真サイズが規格からずれることがあります。必ず100%（原寸）で印刷しましょう。

自宅プリンターの設定

  • 用紙：A4の上質紙または専用履歴書用紙（白・厚みのあるもの）
  • 印刷品質：「きれい」「高品質」を選択（文字のカスレ防止）
  • 色：カラー（写真入りの場合）。モノクロは文字のみなら可
  • 「フチなし印刷」はプリンターによって仕上がりが不安定なので、フチあり100%が無難

用紙の選び方

  • 色：白（クリーム色・色付きは履歴書では避けるのが無難）
  • 厚さ：0.14〜0.18mm程度（コピー用紙より少し厚めの「上質紙」）
  • サイズ：必ずA4（B5は最近少なくなっています）
  • 履歴書専用の市販用紙（罫線入り）も有効ですが、当サイトの印刷レイアウトは罫線込みなので白紙でそのまま使えます

証明写真だけ印刷したいとき

当サイトの写真スタジオでは、仕上げた写真をA4に6枚並べた「印刷シート」として保存できます。コンビニで写真プリント（A4光沢紙）すれば1枚あたり数十円で済みます。

  • 証明写真機：1回800円前後 → 印刷シート：A4約60〜100円程度＋写真用紙代
  • 切り取りはカッター+定規で直線に。化粧ポーチなどに1枚予備を入れておくと安心です
